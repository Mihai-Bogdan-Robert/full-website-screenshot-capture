Capture every page of a website as a full-page screenshot

Full Website Captures is a website screenshot tool that turns a whole site into a set of images. You enter an address, choose how the pages should be found, and a few minutes later you can download a ZIP with one full-page screenshot for every page. There is no account to create, no browser extension to add and nothing to install.

The problem it solves

Taking one screenshot is easy. Taking fifty is not. Browser tools usually capture a single page at a time, cut long pages off at the bottom, miss images that only load as you scroll, and leave cookie banners sitting on top of the content. Doing all of that by hand for an entire website takes hours, and it is easy to forget a page along the way. This tool does the repetitive part for you, so you get a complete and consistent set of screenshots instead.

How it works

  1. Enter the address of the website you want to capture.
  2. Pick how the pages are found. Sitemap reads the site's sitemap.xml, which is fast and complete when the site has one. Crawl starts from the page you entered and follows the links on the same site, so it also works when there is no sitemap. It respects robots.txt.
  3. Choose the viewport: desktop (1920×1080), mobile (390×844, like a phone) or both, which gives you two versions of every page for checking responsive layouts.
  4. Set how many pages to capture and press Start Capturing.
  5. Follow the progress, look through the gallery, and download all screenshots as a ZIP file.

Every page is opened in a real Chromium browser, so modern sites that rely on JavaScript look the way a visitor sees them. The tool closes common cookie banners, scrolls down the page so lazy-loaded images appear, and then captures the page from top to bottom. Screenshots are sent straight to your browser and the ZIP file is built there, so the server does not keep a copy of your images.

Disclaimer

Only public websites can be captured, and pages that sit behind a login are out of reach. Very long or heavy pages can take a little longer, and a page that fails to load is skipped so the rest of the capture can finish. The source code is public, so you can also run the tool on your own computer.
